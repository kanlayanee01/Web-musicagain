# 🎵 Music Again

เว็บแอปพลิเคชันฟังเพลงออนไลน์ ที่ให้ผู้ใช้ค้นหาเพลง ฟังเพลง สร้าง/จัดการเพลย์ลิสต์ และบันทึกเพลงโปรดได้อย่างสะดวก รวดเร็ว พร้อมระบบหลังบ้านสำหรับผู้ดูแลในการจัดการเพลง ศิลปิน และอัลบั้ม

---

## 💡 ที่มาของโครงการ

ปัจจุบันการฟังเพลงออนไลน์ได้รับความนิยมอย่างแพร่หลาย แต่ผู้ใช้บางคนยังหาเพลงที่ต้องการได้ไม่รวดเร็ว หรือเจอปัญหาโฆษณาเยอะจนใช้งานไม่สะดวก **Music Again** จึงถูกพัฒนาขึ้นเพื่อให้ผู้ใช้ค้นหา ฟัง และจัดการเพลงที่ชื่นชอบได้ง่ายในที่เดียว

---

## ✨ ฟีเจอร์หลัก

### 👤 ฝั่งผู้ใช้ (User)
- สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ
- ดูเพลง ศิลปิน และอัลบั้มทั้งหมด
- ค้นหาเพลง / ศิลปิน / อัลบั้ม
- เล่นเพลงออนไลน์ พร้อมควบคุมเล่น/หยุด/ปรับเสียง/เลื่อนแถบเวลา
- สร้าง แก้ไข ลบเพลย์ลิสต์ของตัวเอง และเพิ่ม/ลบเพลงในเพลย์ลิสต์
- บันทึกเพลงโปรด (Favorites) และเข้าถึงได้อย่างรวดเร็ว
- เข้าใช้งานแบบ Guest ได้ (ฟังเพลงแนะนำได้ แต่บันทึกโปรด/สร้างเพลย์ลิสต์ไม่ได้)

### 🛠️ ฝั่งผู้ดูแลระบบ (Admin)
- แดชบอร์ดจัดการระบบแยกต่างหาก
- จัดการเพลง: เพิ่ม/แก้ไข/ลบเพลง กำหนดศิลปินและอัลบั้ม พร้อมอัปโหลดไฟล์เพลง (MP3)
- จัดการศิลปิน: เพิ่มชื่อและรูปภาพศิลปิน
- จัดการอัลบั้ม: เพิ่มชื่ออัลบั้ม เชื่อมกับศิลปิน พร้อมรูปหน้าปก

## 🛠️ เทคโนโลยีที่ใช้

| ส่วนของระบบ | เทคโนโลยี |
|---|---|
| Frontend | HTML5, CSS, JavaScript (Vanilla + AJAX) |
| Backend | PHP |
| ฐานข้อมูล | MySQL / MariaDB |
| Server (Local) | XAMPP (Apache + PHP + MySQL) |
| เครื่องมือออกแบบ | Draw.io (Wireframe และ Sitemap) |

## 🗃️ โครงสร้างฐานข้อมูล

| ตาราง | รายละเอียด |
|---|---|
| **user** | บัญชีผู้ใช้ (username, password, gmail) |
| **artists** | ข้อมูลศิลปิน (ชื่อ, รูปภาพ) |
| **albums** | ข้อมูลอัลบั้ม เชื่อมกับศิลปิน (artist_id) |
| **songs** | ข้อมูลเพลง เชื่อมกับศิลปินและอัลบั้ม พร้อม path ไฟล์เพลง |
| **playlists** | เพลย์ลิสต์ของผู้ใช้แต่ละคน |
| **playlist_songs** | เพลงที่อยู่ในแต่ละเพลย์ลิสต์ พร้อมลำดับเพลง |
| **favorites** | เพลงโปรดของผู้ใช้แต่ละคน |

**ความสัมพันธ์หลัก:** ผู้ใช้ 1 คน → สร้างได้หลายเพลย์ลิสต์และหลายเพลงโปรด | ศิลปิน 1 คน → มีได้หลายอัลบั้มและหลายเพลง | อัลบั้ม 1 อัลบั้ม → มีได้หลายเพลง

## 🚀 การติดตั้งและรันโปรเจกต์ (Local)

โปรเจกต์นี้ใช้ PHP + MySQL รันผ่าน **XAMPP**

```bash
# 1. Clone โปรเจกต์ไปไว้ใน htdocs ของ XAMPP
git clone https://github.com/kanlayanee01/Web-musicagain.git C:\xampp\htdocs\musicweb

# 2. เปิด XAMPP Control Panel แล้ว Start Apache และ MySQL

# 3. สร้างฐานข้อมูลผ่าน phpMyAdmin (http://localhost/phpmyadmin)
#    แล้ว import ไฟล์ musicweb.sql ที่แนบมาในโปรเจกต์

# 4. เปิดเบราว์เซอร์ไปที่
http://localhost/musicweb/
```

> หมายเหตุ: ต้องเพิ่มไฟล์เพลง (mp3) และรูปภาพลงในโฟลเดอร์ `uploads/songs/` และ `uploads/images/` เองก่อนใช้งานฟีเจอร์ครบถ้วน เนื่องจากไฟล์เหล่านี้ไม่ได้รวมอยู่ใน repository
